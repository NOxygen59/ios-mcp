iOS MCP iPad 1.0 — traduction française et jeton d'accès — basé sur iOS MCP 1.2.8

**Version :** iOS MCP iPad **1.0** — basée sur la version officielle iOS MCP **1.2.8**.

## Installation

Télécharger `iOS-MCP-1.2.8-ios16-rootless.deb` et l'ouvrir avec Sileo ou Filza (jailbreak rootless, Dopamine), puis faire un respring. Ou ajouter la source Sileo https://noxygen59.github.io/sileo-repo/ et installer **iOS MCP**.

Ensuite : *Réglages → iOS MCP* → démarrer le serveur, activer **Exiger un jeton d'accès**, puis **Copier la commande Claude Code** et la lancer dans un terminal du Mac.

## Modifications de ce build (20 octobre 2026)
